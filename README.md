# 招新面试时间预约

一个面向社团/实验室招新的面试预约网页，专门解决“同一个时间段最多 2 人”的限制问题。

## 已实现

- 先选年级，再只显示对应年级姓名
- 大二：2026-10-10 至 2026-10-13，每场 5 分钟
- 大一：2026-10-14 至 2026-10-18，每场 10 分钟
- 每天两个时间窗口：14:30-17:00、19:30-21:30
- 每个具体时间段最多 2 人
- 数据库事务二次校验，避免多人同时抢最后一个名额导致超额
- 每个姓名只能预约一次
- 管理后台 `/admin.html`
- 管理后台支持从飞书导出的 CSV 导入姓名/年级
- 管理后台查看预约结果、未预约人员、导出 CSV

## 目录

- `public/`：学生预约页和管理员后台
- `functions/interview-api/`：CloudBase 云函数后端
- `sample-students.csv`：名单格式示例

## CloudBase 部署要点

1. 在腾讯云 CloudBase 创建环境，并开通文档型数据库、云函数、静态网站托管。
2. 部署 `functions/interview-api` 为普通 Node.js 云函数，函数名建议 `interview-api`。
3. 给云函数配置环境变量 `ADMIN_KEY=<你自己的强密码>`。
4. 在 HTTP 网关把路径 `/api/interview` 指向 `interview-api` 云函数，并关闭身份认证（预约页需要匿名访问）。
5. 将 `public/` 部署到静态网站托管。
6. 若前端和 API 不在同一域名，把 `public/config.js` 中的 `window.INTERVIEW_API_BASE` 改成完整 API 地址。
7. 打开 `/admin.html`，输入 `ADMIN_KEY`，导入从飞书导出的 CSV 名单。

## 飞书名单格式

CSV 至少包含两列：

```csv
姓名,年级
张三,大一
李四,大二
```

后台会自动识别“姓名/名字/name”和“年级/grade”表头。

## 数据结构

CloudBase 文档型数据库会使用 3 个集合：

- `students`：候选人名单及是否已预约
- `slots`：各时间段当前已占用人数
- `bookings`：最终预约记录

预约提交时会在服务端事务里同时检查学生状态和时段容量；容量达到 2 后，第三个人会收到“该时间段已满”。
